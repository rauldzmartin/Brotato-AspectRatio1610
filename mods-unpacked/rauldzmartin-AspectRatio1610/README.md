# AspectRatio1610 (Brotato Mod)

**Author:** rauldzmartin  
**Version:** 1.0.1  
**Compatibility:** Brotato v1.1.15.4+ (ModLoader v6.2.0+)  
**Dependencies:** None (Standalone)

---

## Features

- **Native 16:10 Fullscreen Support (Steam Deck, Laptops, 16:10 Monitors)**:
  - **100% Full-screen Gameplay, Shop & End-Run**: Eliminates black letterbox bars during combat and between-wave shops on any 16:10 resolution (1280x800, 1920x1200, 2560x1600, etc.) without stretching or canvas distortion.
  - **Top-Edge HUD Anchoring**: Health, gold, XP, and wave timer are anchored directly to the true top edge of the 16:10 screen.
  - **16:9 Letterbox Menus**: Title screen and selection menus stay crisp, proportionate, and centered with clean 16:9 letterboxing, preserving the hand-crafted 2D art.
- **Borderless Fullscreen at Native Display Resolution**: Automatically applies borderless fullscreen matching your screen resolution on startup.
- **Options Menu Fix**: Repairs the broken vanilla Fullscreen toggle button in the Options menu with persistent user settings saved in `user://fullscreen_mod.json`.
- **Zero External Dependencies & Zero Log Spam**: Lightweight, standalone, and fully optimized.
